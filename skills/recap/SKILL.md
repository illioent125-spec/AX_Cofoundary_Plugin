# recap

사용자가 이것저것 말한 뒤 부르면, AI가 이해한 사용자의 목표와 풀려는 문제를 짧게 되짚는다. 목적은 일을 시작하기 전에 AI와 사용자가 같은 그림을 보고 있는지 확인하는 것이다. 그래서 새 아이디어를 보태지 않고, 사용자가 한 말에서만 뽑는다.

## Workflow

1. **Read**: 이번 대화에서 사용자가 한 말과 함께 붙인 자료를 읽는다. 인자로 덧붙인 말이 있으면 그것도 포함한다. AI가 앞서 제안한 내용은 사용자가 받아들였을 때만 사용자의 뜻으로 친다.
2. **Write**: 아래 형식으로 쓴다. 쉬운 한국어로, 각 줄은 한 문장으로 쓴다.

   ```
   🎯 목표: <결국 이루고 싶은 것>
   🧩 문제: <지금 그걸 막고 있는 것>
   📌 조건: <지켜야 할 것, 쉼표로 이어서>
   ❓ 모르겠음: <아직 말하지 않았거나 헷갈리는 것>
   ```

   - 목표와 문제를 섞지 않는다. 목표는 바라는 끝 상태이고, 문제는 거기까지 못 가게 막는 것이다.
   - 조건이 없으면 `📌` 줄을 뺀다.
   - 모르는 부분은 추측해서 채우지 않고 `❓` 줄에 적는다. 다 분명하면 `❓` 줄을 뺀다. 추측으로 채우면 사용자가 빠뜨린 것을 알아챌 기회를 잃기 때문이다.
   - 말이 거의 없어 목표조차 알 수 없으면 요약하지 않고 "무엇을 하려는지 한두 문장으로 말해 주세요"라고만 한다.
3. **Check**: AskUserQuestion으로 "이렇게 이해한 게 맞나요?"라고 묻는다. 선택지는 `맞아요`, `고칠 게 있어요` 두 개다.
   - 맞으면 멈춘다. 다음 일을 시작하지 않는다.
   - 고칠 게 있으면 무엇이 다른지 듣고, 2번 형식으로 다시 써서 3번을 반복한다.

## Example

사용자가 앞서 이렇게 말했다:
"캐릭터 디자인 툴 만들고 있는데 매번 프롬프트 새로 쓰니까 결과가 들쭉날쭉해. 흰 배경에 전신이랑 얼굴 두 칸으로 나오면 좋겠어."

recap 출력:
```
🎯 목표: 캐릭터 시트를 매번 같은 형식으로 뽑아 주는 디자인 툴 만들기
🧩 문제: 프롬프트를 매번 새로 써서 결과가 들쭉날쭉함
📌 조건: 흰 배경, 서 있는 전신 + 얼굴 클로즈업 2칸
❓ 모르겠음: 누가 쓰는 툴인지(나 혼자 / 팀 / 외부 사용자)
```
